# 주간 양육 가이드 — Weekly Parenting Guide

한국의 0~71개월 영유아를 돌보는 부모·보호자를 위한 AI 양육 지원 스킬입니다. 아이의 월령과 최근 모습을 바탕으로 놀이·보육·교육·훈육·생활습관을 살펴보고, 이번 주에 해볼 일 세 가지와 짧은 관찰 기록을 정리합니다.

부모용 공유 초안 v1.0.0 · 한국어 기본 · Claude / ChatGPT 활용 안내 포함

[주간 양육 스킬 다운로드 (.skill)](https://raw.githubusercontent.com/Jeongin-Choe-RN/weekly-childcare/main/dist/weekly-childcare.skill) · [스킬 내용 보기](SKILL.md) · [English](README.en.md)

## 1. 무엇을 도와주나요?

- 아이에 맞게 시작: 만 월령, 돌봄환경, 가능한 시간, 요즘 관심과 고민을 확인합니다.
- 매주 세 가지 실천: 일상에서 해볼 놀이, 부모가 사용할 말, 생활·훈육 방법을 구체적으로 제안합니다.
- 총체적인 양육 지원: 관계·정서, 언어·인지, 움직임, 수면·식사·구강·배변, 기관 적응, 훈육, 안전·검진, 보호자 부담을 함께 살핍니다.
- 기록하고 이어가기: 지난주에 실제로 관찰한 모습을 다음 계획에 반영합니다. 모든 영역을 매주 숙제로 주지는 않습니다.
- 근거 확인: 국내 공식 안내와 CDC·WHO·미국소아과학회 자료를 참고하고, 부모의 실천 예시와 공식 기준을 구분합니다.

이 스킬은 발달검사·진단·치료 도구가 아닙니다. 임상적 효과나 정확도를 검증한 프로그램으로 소개하지 않습니다.

## 2. Claude에서 사용하기

1. 위의 `주간 양육 스킬 다운로드 (.skill)`를 눌러 파일 하나를 받습니다. 파일 안에 지침과 참고자료가 함께 들어 있으므로 따로 압축을 풀 필요가 없습니다.
2. Claude에서 코드 실행 및 파일 생성 기능을 켜고 `Customize → Skills → + → Create skill → Upload a skill`을 엽니다. 파일 선택창이 `.skill`을 허용하면 받은 파일을 업로드하고 활성화합니다. 지원하는 파일 형식과 메뉴는 계정·버전에 따라 달라질 수 있으므로, 파일을 선택할 수 없다면 아래 공식 설치 안내를 확인하세요.
3. 새 대화에 다음처럼 입력합니다. 정확한 생일이나 이름 없이 월령만으로 시작할 수 있습니다.

   > weekly-childcare 스킬로 이번 주 양육을 도와주세요. 아이는 만 22개월이고 어린이집에 다녀요. 평일에는 함께 놀 시간이 10분 정도예요. 요즘 장난감을 던질 때 어떻게 반응할지 고민이에요.

4. AI가 필요한 정보를 확인하면 아는 범위에서 답하고 주간 안내를 받습니다.
5. 다음 주에는 새로 본 모습, 어려웠던 상황, 가능한 시간을 알려줍니다.

설치 근거: [Claude 공식 스킬 사용 안내](https://support.claude.com/en/articles/12512180-use-skills-in-claude). 설치 파일 구조는 확인했으며, 각 사용자의 Claude 계정에서의 설치·작동 확인은 별도로 필요합니다.

## 3. ChatGPT에서 사용하기

### 개인 스킬을 만들 수 있는 환경

`SKILL.md`와 함께 제공된 `references`, `templates`, `scripts` 파일을 전달하고 "이 자료로 weekly-childcare 개인 스킬을 만들어 주세요"라고 요청합니다. 스킬이 생성·활성화되면 이름을 선택하거나 "주간 양육 가이드로 이번 주 계획을 만들어 주세요"라고 요청합니다. Claude의 `.skill` 파일을 ChatGPT의 모든 계정에서 그대로 설치할 수 있다는 뜻은 아닙니다.

### 일반 대화에서 시작하기

[ChatGPT 시작 안내](docs/CHATGPT_START.md)를 대화에 첨부하거나 내용을 붙여 넣고 아이의 만 월령과 고민을 알려주세요. 이 경로는 안내문을 활용한 대화이며 개인 스킬이 설치되는 것은 아닙니다. 자세한 근거가 필요하면 [근거자료](references/evidence.md)도 함께 첨부할 수 있습니다.

기능 근거: [ChatGPT 스킬 안내](https://learn.chatgpt.com/docs/skills-and-plugins), [스킬 작성 안내](https://learn.chatgpt.com/docs/build-skills).

## 4. 다섯 단계로 사용해요

| 단계 | 부모가 하는 일 | 받는 도움 |
|---|---|---|
| 1. 아이 이해 | 월령·돌봄환경·관심·고민을 알려주기 | 이번 안내의 범위 정하기 |
| 2. 지난주 돌아보기 | 실제로 본 모습을 짧게 적기 | 유지할 것과 바꿀 것 구분 |
| 3. 이번 주 정하기 | 가능한 시간과 상황 알려주기 | 우선순위 세 가지 |
| 4. 생활에서 해보기 | 놀이·말·생활 방법을 시도하기 | 구체적인 예시와 쉬운 대안 |
| 5. 기록하고 이어가기 | 잘 된 점·어려운 점 남기기 | 다음 주 계획에 반영 |

처음이라면 2단계는 건너뜁니다. 매주 새로운 능력이 나타나야 하는 것은 아니며, 놓친 주의 활동을 몰아서 할 필요도 없습니다.

## 6. 공유와 개인정보

- GitHub는 공통 스킬·근거·빈 양식·가상 예시를 배포하는 곳입니다. 사용자의 아이 정보가 기본값으로 들어 있지 않습니다.
- 실제 아동의 생년월일·사진·병력·관찰일지를 이 저장소나 공개 Issues에 올리지 마세요. 개인 대화 또는 별도의 비공개 보관 장소에서 다룹니다.
- 스킬의 월령 계산 스크립트는 네트워크 통신이나 외부 기록 저장을 하지 않습니다. 이용하는 AI 서비스의 대화·파일 데이터 처리는 해당 서비스의 설정과 정책을 따릅니다.
- 피드백에는 아동을 식별할 정보 없이 사용한 기능, 불편했던 점, 익명화한 문장만 남겨주세요. 개발자에게 개별 발달 진단을 요청하는 용도로 사용하지 않습니다.

## 7. 매주 알림과 업데이트

스킬 설치만으로 주간 알림이 생기지는 않습니다. 예약 작업을 지원하는 환경에서 별도로 일정을 요청하고, 예약 완료 안내를 확인하세요. 지원하지 않는 환경에서는 개인 캘린더에 알림을 두고 대화를 다시 시작하면 됩니다.

GitHub 파일의 수정이 이미 설치한 모든 스킬에 자동 반영되는 것은 아닙니다. 새 배포본을 받으면 사용하는 서비스의 교체·업데이트 방법에 따라 적용하세요. 저장소를 연결해 자료를 읽는 것과 스킬을 설치하는 것도 구분됩니다.

## 8. 사용 범위와 근거

- 현재 기본 범위는 한국에서 양육하는 0~71개월 영유아입니다. 다른 국가나 연령에는 해당 기준을 별도로 확인합니다.
- 의료적 특이사항·미숙아·발달 우려가 있으면 담당 의료진의 안내를 우선합니다. 하던 말이나 행동이 사라지거나 걱정이 지속되면 정기검진까지 기다리지 말고 상담하세요.
- AI는 출처와 내용을 잘못 연결할 수 있습니다. 최신 조회가 불가능하면 그 사실을 표시하도록 구성했습니다. 공식 기준과 아이의 개별 검진 결과를 확인하세요.
- 참고자료의 확인일은 2026-10-14입니다. 이후의 제도·지침 개정은 사용 시 다시 확인합니다.
